# 真实政策文件样例

这三份文件来自公开的政府网站，带有文字层，用于验证 `clauseanchor parse`
在真实版式上的条款切分、页码对应、生效日期与发文字号抽取。文件保留原始
PDF，不做任何内容改写。

核对命令：

```bash
uv run clauseanchor parse examples/real/sh_market_reg_archive_lookup.pdf
uv run clauseanchor parse examples/real/sh_market_reg_archive_lookup.pdf --json
```

## 已知边界

- 三份样例覆盖两类发文方式：两份市属部门联合发文（上海市市场监督管理局、上海市档案局；上海市药品监督管理局、上海市卫生健康委员会），一份市级人民政府发文（上海市人民政府）。真实红头文件的版式差异仍然存在：例如有的
  PDF 正文不包含发文机关署名或发文字号，解析器会把这几项报为未识别，而
  不会猜测填充。
- 样例都是有文字层的 PDF。扫描件不在 v0.1 范围内。
